# IoT Pet Tracker

A real-time GPS and motion tracking system for pets. Wearable tracker nodes collect GPS location, speed, and behavior data (idle/walking/running/sitting) and transmit it over LoRa to a base station, which serves a live web dashboard over WiFi. All devices run on Heltec WiFi LoRa V4 (ESP32-S3) boards.
