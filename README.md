# IoT Pet Tracker

A real-time GPS and motion tracking system for pets. Tracker nodes collect GPS location and behavior data (idle/walking/running/sitting) and transmit them over LoRa to a base station, which serves a live webpage over WiFi. Node locations are then displayed visually on a map. Claude was used help us design and implement Websockets and refine the JS for tracking runs as well as storing them locally in the browser.
